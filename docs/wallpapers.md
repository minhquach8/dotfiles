## Installation

Open System Settings > Wallpaper.

Select the appropriate image separately for each display.

Use Fill Screen because the images have already been
prepared for their target aspect ratios.

Enable Show on all Spaces when desired.

The two Philips images are complementary sections
of the same panoramic artwork.

Swap their assignments if the physical monitor
arrangement is reversed.

## Multi-Monitor Layout

Current reference setup:

- Two Philips 1920x1080 external displays
- Built-in MacBook Retina display
- SketchyBar at the top
- AeroSpace tiling window manager

Accepted AeroSpace top gaps:

- Built-in Retina: 12
- External monitors: 44

These values were verified against the live desktop
on 26 October 2026.

## Reproducibility

The PNG files are version-controlled assets.

macOS wallpaper assignments must still be restored
manually through System Settings.

This repository does not modify the macOS wallpaper
database or automatically reset wallpaper preferences.
